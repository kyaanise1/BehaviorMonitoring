Case

Ground truth first. If you can't reliably follow this physical chicken across the window, choose No or Uncertain instead of guessing.

1. Can you reliably identify the SAME physical chicken through the review window?
2. Was the entire observation window recorded continuously and visibly?
3. Did its body-center position stay within the allowed range for the whole 30 minutes?

Use the max–min horizontal and vertical centroid range, not head movements. A repeated frozen image is not evidence of actual inactivity.

4. Optional diagnostic: Did the SYSTEM tracking ID remain on this chicken?

Answer this after manual labeling, using your separate tracking overlay if needed. For zero flock alerts, a tracking switch does not automatically exclude an independently followable physical chicken.

Save and resume

Labels are saved in this browser when supported. Export annotations.csv regularly; that's the permanent file used for scoring. You can import that CSV to resume later.

Data remains local. This page uses no server or network request. The review starts at the first sampled frame and selects birds using their initial positions. This is a targeted, sampled evaluation; it does not automatically measure whole-flock sensitivity or replace independent full-video labeling. After exporting, run the Python score command.
